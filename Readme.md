# Caesar Cipher

A simple Python Caesar cipher program that encodes or decodes text by shifting letters through the alphabet.

## Features

- Encodes and decodes messages
- Supports uppercase and lowercase input
- Keeps letters and symbols aligned within the alphabet
- Allows repeated use

## Run

Open `main.ipynb` in Jupyter Notebook and run the cells.

## Concepts

- Functions with inputs
- Positional and keyword arguments
